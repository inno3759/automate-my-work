PASS if the plan (a) starts with a capability check or says it will look at what is installed on the computer, (b) proposes to record one real pass to find the download request and replay it, (c) mentions running without the person present (a button or a schedule), and (d) keeps a human confirmation or dry run before anything irreversible. FAIL if the first proposal is a browser-clicking robot without justification, or if it tells the person to install Python from a website themselves.
